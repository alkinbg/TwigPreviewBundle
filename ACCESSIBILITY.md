# Accessibility

Twig Preview Bundle aims to keep its built-in preview index usable without JavaScript. The index uses semantic HTML, a page heading, and a list of standard links that can be navigated with a keyboard.

Preview pages render **your application's templates**, so their accessibility depends on the markup, styles, and components supplied by the application. The bundle does not modify or audit them.

If you find an accessibility problem with the **bundle's own index page or controls**, please open an [issue](https://github.com/alkinbg/TwigPreviewBundle/issues/new), mention accessibility, and include the browser, assistive technology if relevant, and steps to reproduce.
