# Changelog

## [1.0.0] - 2026-10-19

Initial stable release.

- Discover and render named Twig previews in a Symfony application's development environment.
- Provide an index page and development-only preview routes.
- Load optional JSON fixture data with strict name, format and size validation.
- Return explicit 404/400 responses for missing previews and invalid fixtures.
- Disable caching and search-engine indexing for preview responses.
- Document installation, usage, examples, limitations and security boundaries.
- Test PHP 8.2–8.4 and integrate against the real Symfony HTTP kernel.
