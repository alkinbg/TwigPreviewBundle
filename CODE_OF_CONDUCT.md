# Code of Conduct

Twig Preview Bundle is a small open-source project. Contributions, questions, and constructive feedback are welcome, regardless of experience level.

## Expected behavior

- Be respectful, patient, and considerate when discussing changes.
- Assume good intent, but accept corrections and respond constructively.
- Focus criticism on code and ideas, not on people.
- Welcome newcomers and help keep discussions useful and on topic.
- Respect people's privacy. Do not publish personal information or private conversations without permission.

Harassment, threats, discriminatory language, personal attacks, and deliberate disruption are not acceptable in project spaces.

## Scope

These guidelines apply to issues, pull requests, code reviews, and other interactions representing this project.

## Reporting and enforcement

For a concern that should remain private, email **alkinbg@gmail.com** with the subject **TwigPreviewBundle: Code of Conduct**. Do not post sensitive details in a public issue.

The maintainer will review reports in context and may edit or remove content, close conversations, or limit participation to keep the project welcoming. No response-time guarantee is implied.

For security vulnerabilities, follow [SECURITY.md](SECURITY.md) instead.
